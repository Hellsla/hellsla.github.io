## fy3-5-L1-01
**Annettu:** systeemi on taikina; käsien tekemä työ W = +450 J (ympäristö tekee työtä taikinaan), käsistä siirtyvä lämpö Q = +120 J (lämpöä siirtyy taikinaan)
**Kysytty:** ΔU
**Kaava:** ΔU = Q + W
**Sijoitus:** ΔU = 120 J + 450 J = 570 J
**Vastaus:** 570 J
**Järkevyys:** Molemmat energiansiirrot tuovat energiaa taikinaan, joten sisäenergia kasvaa niiden summan verran. Vaivattu taikina lämpenee hieman, mikä sopii kokemukseen.

## fy3-5-L1-02
**Annettu:** systeemi on kahvi; Q = −8,4 kJ (lämpöä siirtyy kahvista pois), W = 0
**Kysytty:** ΔU
**Kaava:** ΔU = Q + W
**Sijoitus:** ΔU = −8,4 kJ + 0 = −8,4 kJ
**Vastaus:** −8,4 kJ
**Järkevyys:** Sisäenergia pienenee, joten kahvin lämpötila laskee. Energia ei katoa, vaan sama 8,4 kJ siirtyy pöytään ja huoneen ilmaan.

## fy3-5-L1-03
**Annettu:** systeemi on pallon ilma; Q = +350 J (lämpöä siirtyy ilmaan), W = −100 J (ilma tekee työtä ympäristöön laajetessaan)
**Kysytty:** ΔU
**Kaava:** ΔU = Q + W
**Sijoitus:** ΔU = 350 J + (−100 J) = 250 J
**Vastaus:** 250 J
**Järkevyys:** Osa tulevasta energiasta kuluu laajenemistyöhön, joten sisäenergia kasvaa vähemmän kuin 350 J. Sisäenergia kasvaa silti, joten ilman lämpötila nousee.

## fy3-5-L1-04
**Annettu:** systeemi on palokaasu; W = −320 J (kaasu tekee työtä mäntään), Q = −180 J (lämpöä siirtyy kaasusta seiniin)
**Kysytty:** ΔU
**Kaava:** ΔU = Q + W
**Sijoitus:** ΔU = −180 J + (−320 J) = −500 J
**Vastaus:** −500 J
**Järkevyys:** Energiaa lähtee kaasusta kahta reittiä eikä tule mitään, joten sisäenergia pienenee kummankin siirron verran ja kaasu jäähtyy.

## fy3-5-L1-05
**Annettu:** systeemi on purkautuva ilma; W = −85 J (ilma tekee työtä ympäristöön), Q = +15 J (lämpöä siirtyy ilmaan)
**Kysytty:** ΔU
**Kaava:** ΔU = Q + W
**Sijoitus:** ΔU = 15 J + (−85 J) = −70 J
**Vastaus:** −70 J
**Järkevyys:** Laajenemistyö vie enemmän energiaa kuin lämpö tuo, joten sisäenergia pienenee ja ilma jäähtyy. Siksi venttiili tuntuu kylmältä, kun ilmaa päästetään ulos.

## fy3-5-L2-01
**Annettu:** systeemi on ilma; F = 300 N, s = 0,20 m, ΔU = +45 J
**Kysytty:** Q
**Kaava:** W = F s ja ΔU = Q + W, joten Q = ΔU − W
**Sijoitus:** W = 300 N · 0,20 m = 60 J (ympäristö tekee työtä ilmaan, joten W on positiivinen). Q = 45 J − 60 J = −15 J
**Vastaus:** −15 J
**Järkevyys:** Työ toi ilmaan 60 J, mutta sisäenergia kasvoi vain 45 J. Erotus 15 J on siirtynyt lämpimästä ilmasta sylinterin seiniin, joten Q on negatiivinen.

## fy3-5-L2-02
**Annettu:** systeemi on vesi; P = 2,0 kW = 2000 W, t = 90 s, lämpöä ulos 20 kJ
**Kysytty:** ΔU
**Kaava:** vastuksen luovuttama energia P t; ΔU = Q + W, missä W = 0
**Sijoitus:** P t = 2000 W · 90 s = 180 000 J = 180 kJ. Q = 180 kJ − 20 kJ = 160 kJ, joten ΔU = 160 kJ + 0 = 160 kJ
**Vastaus:** 160 kJ
**Järkevyys:** Suurin osa vastuksen energiasta jää veteen ja vain pieni osa karkaa kuoren läpi. Puolentoista minuutin keitto lämmittää vettä selvästi, mikä sopii.

## fy3-5-L2-03
**Annettu:** systeemi on höyry; W = −2,0 kJ = −2000 J (höyry tekee työtä), ΔU = −1,2 kJ = −1200 J
**Kysytty:** Q
**Kaava:** ΔU = Q + W, joten Q = ΔU − W
**Sijoitus:** Q = −1200 J − (−2000 J) = 800 J
**Vastaus:** 800 J
**Järkevyys:** Q on positiivinen, joten lämpöä siirtyy höyryyn. Höyry tekee enemmän työtä kuin sen sisäenergia pienenee; erotus 800 J siirtyy höyryyn lämpönä sylinterin kuumista seinistä.

## fy3-5-L2-04
**Annettu:** systeemi on smoothie; P = 250 W, t = 40 s, Q = +2,0 kJ (smoothie on ympäristöä kylmempää, joten lämpöä siirtyy siihen)
**Kysytty:** ΔU
**Kaava:** W = P t ja ΔU = Q + W
**Sijoitus:** W = 250 W · 40 s = 10 000 J = 10 kJ. ΔU = 2,0 kJ + 10 kJ = 12 kJ
**Vastaus:** 12 kJ
**Järkevyys:** Sekä terän työ että keittiön lämpö tuovat energiaa, joten sisäenergia kasvaa. Pitkään sekoitettu smoothie lämpenee, vaikka sekoitin ei lämmitä sitä millään vastuksella.

## fy3-5-L3-01
**Annettu:** systeemi on pumpun ilma (määrä ei muutu); F = 120 N, s = 0,15 m, lämpötila vakio
**Kysytty:** Q
**Kaava:** W = F s ja ΔU = Q + W
**Sijoitus:** Sisäenergia riippuu lämpötilasta ja aineen määrästä. Kumpikaan ei muutu, joten ΔU = 0. W = 120 N · 0,15 m = 18 J (työtä tehdään ilmaan). 0 = Q + 18 J, joten Q = −18 J
**Vastaus:** −18 J
**Järkevyys:** Koska mäntää painetaan hitaasti, työn tuoma energia ehtii siirtyä lämpönä pumpun seinien kautta huoneeseen. Nopeasti painettaessa lämpö ei ehtisi siirtyä, ja pumppu kuumenisi.

## fy3-5-L3-02
**Annettu:** systeemi on vesi; m = 5,0 kg, n = 12 laskeutumista, ΔU = 1,0 kJ = 1000 J, g = 9,81 m/s², eristetty astia
**Kysytty:** laskeutumiskorkeus h
**Kaava:** ΔU = Q + W, missä Q = 0; yhden laskeutumisen työ W₁ = m g h, joten ΔU = n m g h
**Sijoitus:** h = ΔU / (n m g) = 1000 J / (12 · 5,0 kg · 9,81 m/s²) = 1000 J / 588,6 N = 1,699 m
**Vastaus:** 1,7 m
**Järkevyys:** Eristetty astia ei päästä lämpöä ulos, joten koko työ jää veden sisäenergiaksi. Noin 1,7 metrin pudotus mahtuu luokkahuoneeseen. Yksiköt: J / N = m.

## fy3-5-L3-03
**Annettu:** kaasu tekee työn 250 J ympäristöön, joten W = −250 J; ΔU = −90 J
**Kysytty:** Q etumerkkeineen
**Kaava:** ΔU = Q + W, joten Q = ΔU − W
**Sijoitus:** Q = −90 J − (−250 J) = −90 J + 250 J = 160 J
**Vastaus:** +160 J, lämpöä siirtyy kaasuun
**Järkevyys:** Laajeneva kaasu luovuttaa työnä 250 J. Jos lämpöä ei siirtyisi, sisäenergia pienenisi koko 250 J. Koska se pienenee vain 90 J, erotus 160 J on tullut kaasuun lämpönä.
