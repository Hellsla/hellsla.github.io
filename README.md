# FY3-kuvien lataus

[**Lataa kaikki 68 PNG-kuvaa ZIP-pakettina**](https://github.com/Hellsla/hellsla.github.io/raw/refs/heads/fy3-kuvat-download-20261115/FY3-kuvat-uudet.zip)

ZIP sisältää 68 kuvaa out-kansiossa, raportin ja tiedostoluettelon. Kuvaajat (3-kuvaajat) on ohitettu.

Kuvat ovat sisäänrakennetulla kuvageneroinnilla tuotettuja rasterikuvia. Kuvasuhteen poikkeama alkuperäisestä on enintään 0,17 %. Kaavioiden mittasuhteiden ja värikoodien täsmällisyyttä ei ole varmennettu.

SHA256SUMS.txt sisältää ZIP-tiedoston tarkistussumman.
