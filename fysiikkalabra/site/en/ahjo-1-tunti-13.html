Lesson 13 · Robotics

A square blind, then with a sensor

Programming a robot

Timed moves, measuring and a first sensor trial.

In this lesson you learn: You program the robot's moves and try how a sensor changes what the robot does.

Start right away (5–10 min)

Change the test sketch so that the robot drives a square: straight and a turn, four times. How close to the start does it come back?

Try · Modify · Challenge yourself

  1. Try for everyone

    Adjust the driving time and the turning time until the square closes. Measure three times how far from the start the robot stops.

  2. Modify your own ideas

    Do a simple sensor trial: fit a push button to the robot's front as a bump switch and add a condition to the program that stops the robot when the button is pressed. The instructions are at the end of the test sketch.

  3. Challenge yourself optional

    Try a distance or line sensor, if one is available, and compare over three runs how the time and the accuracy change.

If you have to wait

If the robot is busy, write the square program in advance and work out the driving time from the speed you measured in lesson 12. Meanwhile mark the course on the floor with tape.

What did you make?

Basic level: A robot that drives a square with timed moves, the measured return accuracy and a sensor trial where the robot stops at the button.

Challenge yourself: A comparison of the sensor-controlled run: time and accuracy over three runs.

Together

Run another pair's program on your robot and tell them where the robot left the route.

You need

  • robot base from lesson 12
  • computer and the Arduino IDE
  • push button and two wires for the sensor trial
  • masking tape to mark the course and a tape measure

Starter files

  • Robot test sketch (Arduino) untested draft: the robot base is not chosen yet, check the pins

Safety

Test a new program first with the robot's wheels in the air. Drive the robot on the floor in a clear area, and keep cables and feet off the course.
