Lesson 14 · Your own drone project

First working version

Building and programming the project

The project is built or programmed far enough that it can be tried out.

In this lesson you learn: You build the first version of your plan and try it out.

Needs the teacher's safety approval

Start right away (5–10 min)

Read this session's target from the plan and share out the work. Every member of the group has a task during the first five minutes.

Project journal →

Try · Modify · Challenge yourself

  1. Try for everyone

    Build or program the first version of the project and do one test with it, even if not everything works yet. Record what happened.

  2. Modify your own ideas

    Improve one thing on the basis of the first test and record what you changed and why.

  3. Challenge yourself optional

    Prepare a measurement for next time: make a table for the measurements and decide how many repeats are needed.

If you have to wait

If the device you need is in use, work on another part of the project: the table for the measurements, the 3D model or the documentation.

What did you make?

Basic level: The first version of the project and a record of the first test.

Challenge yourself: One justified improvement, or a finished measurement plan.

Write in your project diary

  • what was done and who did it
  • the result of the first test
  • the target for next time

Together

Show your unfinished work to another group and ask one question that you need help with.

You need

  • the equipment listed in the project plan
  • project diary
  • charged batteries, if you fly

Step-by-step guide

  • Project journal
  • Flight tests and measuring

Safety

Follow the safety section of your plan. If the plan changes so that you fly in a different way, ask for a new approval.

  • Drones: propellers and motors
  • Drones: charging and storing batteries
  • Drones: flight area and roles
  • Drones: emergency stop and abnormal situations

Ahjo's safety instructions are still being prepared. Follow your teacher's induction.

For the teacher: preparation and timing

Timing: Sharing out the work 5 min, building and programming 55 min, diary and tidying up 15 min.

Preparation: Make an equipment booking list from the groups' plans. Charge the batteries. Agree where the groups that fly will work, and when.
