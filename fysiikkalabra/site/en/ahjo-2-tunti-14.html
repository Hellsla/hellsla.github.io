Lesson 14 · Present

Finishing and user guide

In your project now: Last fixes, appearance and usability.

A lesson is a guiding model, not an order that binds every group. If your group is at another stage, agree the next step with the teacher and record in the journal what you actually did.

In this lesson you learn: You finish the solution so that the user manages without you.

Next task

Finish the solution for the show: case, labels and a user guide that let the user manage without its maker. If finishing changes how it works, for example a case covers a sensor or a wire moves, check that it works again before the show.

If you have to wait

If the printer or another device is busy, write the user instructions meanwhile and try them out on another group.
