## fy3-15-L1-01
**Annettu:** η₁ = 0,920 (turbiini), η₂ = 0,980 (generaattori)
**Kysytty:** koko laitoksen hyötysuhde η
**Kaava:** η = η₁ · η₂
**Sijoitus:** η = 0,920 · 0,980 = 0,9016 = 90,2 %
**Vastaus:** 90,2 %
**Järkevyys:** Tulos on pienempi kuin kumpikaan osahyötysuhde, kuten tulon pitääkin, kun tekijät ovat alle 1. Vesivoimalaitos ei ole lämpövoimakone, joten sen hyötysuhde voi olla yli 90 %.

## fy3-15-L1-02
**Annettu:** P_tuuli = 2,50 MW, P_sähkö = 1,05 MW
**Kysytty:** hyötysuhde η
**Kaava:** η = P_sähkö / P_tuuli
**Sijoitus:** η = 1,05 MW / 2,50 MW = 0,420 = 42,0 %
**Vastaus:** 42,0 %
**Järkevyys:** Nykyaikaisen tuulivoimalan hyötysuhde on noin 40–45 %. Loput jatkaa ilmavirran liike-energiana roottorin taakse tai häviää laitteiston kitkaan ja sähköhäviöihin; tuulesta ei kuitenkaan voi ottaa kaikkea energiaa, koska ilman on liikuttava vielä roottorin jälkeenkin.

## fy3-15-L1-04

**Kaava:** P_h = P₀ − P_s

**Järkevyys:** Hyötysuhde on 320/800 = 0,40, mikä on lauhdevoimalaitokselle tavallista. Energia säilyy: kun sähkö ei ole hukassa, loput 60 % siirtyy lämpönä savukaasuihin ja lauhduttimen kautta mereen.

## fy3-15-L1-05
**Annettu:** P₀ = 250 MW, P_s = 75 MW, P_k = 150 MW
**Kysytty:** kokonaishyötysuhde η_kok
**Kaava:** η_kok = (P_s + P_k) / P₀
**Sijoitus:** η_kok = (75 MW + 150 MW) / 250 MW = 225 MW / 250 MW = 0,900 = 90,0 %
**Vastaus:** 90 %
**Järkevyys:** Tulos on yhteistuotannon tavallisella välillä 85–90 %. Hukkalämmön teho on 250 MW − 225 MW = 25 MW. Sähkön osuus on vain 75/250 = 30 %, joten sähköhyötysuhde on pienempi kuin lauhdevoimalaitoksessa.

## fy3-15-L2-01

**Kaava:** P₃ = η₁ · η₂ · η₃ · P₀

## fy3-15-L2-03
**Annettu:** P_s = 150 MW = 150 · 10⁶ W, η = 0,360, H = 9,00 MJ/kg = 9,00 · 10⁶ J/kg
**Kysytty:** polttoaineen massa tunnissa m
**Kaava:** polttoaineteho P₀ = P_s / η ja P₀ = H · m / t, joten m = P₀ t / H = P_s t / (η H)
**Sijoitus:** P₀ = 150 MW / 0,360 = 416,7 MW. m = 416,7 · 10⁶ W · 3600 s / (9,00 · 10⁶ J/kg) = 1,667 · 10⁵ kg = 167 t
**Vastaus:** 167 t
**Järkevyys:** Hakkeen virta on noin 46 kg/s, eli noin 4 000 tonnia vuorokaudessa. Sellainen laitos tarvitsee jatkuvaa rekka- tai junakuljetusta, mikä sopii isoihin biovoimalaitoksiin.

## fy3-15-L2-04

**Kaava:** P_h = c · q_m · ΔT, joten q_m = P_h / (c ΔT)

## fy3-15-L3-01
**Annettu:** P₀ = 600 MW. Pelkkä sähkö: P_s = 240 MW. Täysi yhteistuotanto: P_s = 180 MW, P_k = 348 MW. Nyt P_k = 200 MW
**Kysytty:** sähköteho P_s ja kokonaishyötysuhde η_kok
**Kaava:** P_s = 240 MW − (60 MW / 348 MW) · P_k ja η_kok = (P_s + P_k) / P₀
**Sijoitus:** P_s = 240 MW − (60/348) · 200 MW = 205,5 MW ≈ 206 MW. η_kok = (205,5 MW + 200 MW) / 600 MW = 0,676 = 67,6 %
**Vastaus:** 206 MW
**Järkevyys:** Tulokset ovat ääritilojen välissä (40 % ja 88 %). Jokaista kaukolämpömegawattia kohti sähköä menetetään 60/348 = 0,17 MW. Kokonaishyötysuhde laskee yhteen kahta eri arvoista energiaa: sähkö kelpaa kaikkeen, kaukolämpö vain lämmitykseen. Kannattavuus riippuu tarpeesta ja hinnoista.

## fy3-15-L3-02

**Kysytty:** hiilen massa m
**Kaava:** E = η · Q₁ ja Q₁ = H · m, joten m = E / (η H)
**Sijoitus:** m = 1,296 · 10¹⁴ J / (0,380 · 25,0 · 10⁶ J/kg) = 1,364 · 10⁷ kg = 13,6 kt
**Vastaus:** 13,6 kt

Tuulipuiston 0,42 kertoo vain, kuinka suuri osa roottorin läpi virtaavan ilman liike-energiasta saadaan sähköksi.

## fy3-15-L3-03
**Annettu:** Q = 100 kWh, ε = 3,00, η_voimala = 0,400, siirron osuus 0,950
**Kysytty:** voimalaitoksen polttoaineen energia E_polttoaine
**Kaava:** lämpökertoimesta ε = Q / E_s, joten E_s = Q / ε, ja polttoaine E_polttoaine = E_s / (0,950 · η_voimala)
**Sijoitus:** E_s = 100 kWh / 3,00 = 33,3 kWh. E_polttoaine = 33,3 kWh / (0,950 · 0,400) = 33,3 kWh / 0,380 = 87,7 kWh
**Vastaus:** 87,7 kWh
**Järkevyys:** Suora sähkölämmitys vaatisi 100 kWh / 0,380 = 263 kWh polttoainetta ja öljykattila 100 kWh / 0,900 = 111 kWh. Lämpöpumppu säästää polttoainetta eniten, koska se siirtää ulkoilman lämpöä sisälle sen sijaan, että muuttaisi sähkön lämmöksi. Suora sähkölämmitys on huonoin, koska sähkön tuotannossa on jo hukannut yli 60 % polttoaineen energiasta.
