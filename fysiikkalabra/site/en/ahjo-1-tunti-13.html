Lesson 13 · Robotics

A course blind first, then with sensors

Programming a robot

Movement, sensor control and solving a task with a program.

Start right away (5–10 min)

Program the robot to drive a square. How close to the start does it come back?

Try · Modify · Challenge yourself

  1. Try for everyone

    Drive the course using only distances and angles calculated in advance, as when steering a space probe.

  2. Modify your own ideas

    Add a sensor to the robot and let it find the route itself.

  3. Challenge yourself optional

    Compare the rounds: measure the time and the accuracy with three repetitions.

What did you make?

Basic level: A robot that drives the track with pre-programmed moves, and a first try with a sensor.

Challenge yourself: A comparison of the rounds: time and accuracy over three repetitions.

You need

  • the assembled robot
  • computer
  • masking tape to mark the track
