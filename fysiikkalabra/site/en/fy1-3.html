Measuring and the reliability of a measurement

Why do ten students get ten different results for the rolling time of the same ball, even though they all use the same stopwatch?

In this lesson, you will learn to

  • tell gross error, random error and systematic error apart and recognise their sources.
  • calculate a mean and estimate the scatter of the results using half of the range.
  • correct a systematic error and judge whether a measurement is repeatable and accurate.

Prior knowledge

  • A measurement result is given as a numerical value and a unit, and significant figures tell how precise it ischapter Quantities, units and the SI system

Core path: follow the steps in order. Besides calculations, the core path includes investigations, explanations and graphs. Tasks marked Optional give extra practice. Optional tasks: 2.

1Think about it

In a physics lesson the class measures the time a ball takes to roll from the top of a ramp to the bottom. Everyone has a similar hand stopwatch and presses it with their own hand. Still, the results are $2.18\,\text{s}$, $2.45\,\text{s}$, $2.68\,\text{s}$, $2.67\,\text{s}$, $2.40\,\text{s}$ and so on. The teacher says that the true time of the ball exists, but does not tell it.

How can the class get a reliable result from these, and how can they know that the stopwatch is not wrong in the same way for everyone?

Revise significant figures

The stopwatch shows the rolling time of the ball as $2.40\,\text{s}$. What does the last zero tell you?

  • As numbers the values are the same, but as measurement results they are not: $2.4\,\text{s}$ says that the reading was taken in tenths, and $2.40\,\text{s}$ that the stopwatch shows hundredths. So the trailing zero must not be left out. Even so, the precision of the reading is not a hundredth when the time is taken by hand.

  • Digits tell the precision of a reading, not whether the stopwatch is correct. A stopwatch can show hundredths and still show the same amount too much every time.

  • Correct. $2.40\,\text{s}$ is given with three significant figures, and the last one is in the hundredths place: the stopwatch shows the hundredths. The uncertainty of a time taken by hand can still be much larger, because reaction time varies. In this chapter you learn to estimate it.

  • A measurement result does not give an exact value. The number of significant figures tells how far you can trust the result, not that the true value is exactly that.

Assumptions of the model

The values are model values calculated by the simulation, not measurements of a real experiment. The true rolling time of the ball is $T = 2.40\,\text{s}$. The model knows it, but in a real experiment it is not known. A reading is $t_i = T + \Delta t_\text{sys} + \Delta t_\text{ran}\,g_i$ rounded to hundredths of a second, where $g_i$ is a fixed series of random numbers. The same series always starts from the beginning, so the experiment can be repeated. The number $\Delta t_\text{ran}$ is the typical deviation of a single reading; half of the range of many readings is larger than it.

How the calculation works

The mean $\bar{t}$ is the sum of the first $n$ readings divided by $n$. Half of the range is $\Delta t = \dfrac{t_\text{max} - t_\text{min}}{2}$. The difference of the mean from the true time is $\bar{t} - T$, and you can see it only in the model, because the true time is not usually known.

    4Theory

    Key idea

    A measurement means determining the value of a quantity by comparing it with a unit. A measurement result is a numerical value and a unit, for example $2.43\,\text{s}$. The result usually differs a little from the true value of the quantity, because reading the instrument, the method of measuring and the conditions all add a deviation to it. The difference $x - x_\text{true}$ between the result and the true value is the measurement error. Every measurement result has some uncertainty, even one made by a skilled measurer. The true value is usually not known, so neither is the measurement error or its size. Therefore the measurement uncertainty is stated together with the result. It is an estimate of how large the measurement error can be. It does not usually mean an absolute largest possible deviation from the true value.

    Errors are divided into three kinds: gross error, random error and systematic error. You can tell them apart by how they behave when the measurement is repeated.

    Gross error

    A gross error is a single clear mistake: the instrument is read wrongly, a number is recorded wrongly (for example $3.52\,\text{s}$ instead of $3.25\,\text{s}$), the stopwatch is accidentally started only once the ball is already moving, or the result is recorded in the wrong unit. It usually shows up as a result that differs clearly from the others. A gross error is not estimated or averaged but looked for: the odd result is checked, and the measurement can be repeated if necessary. A result is not removed merely because it differs from the others: it is left out of the calculations only if the cause of the error is found, and leaving it out is justified and recorded.

    Random error

    A random error varies from one measurement to the next by chance and can be in either direction. When the rolling time of a ball is measured with a hand stopwatch, it comes from reaction time: sometimes the stopwatch is started a little too early and sometimes too late. Reading a scale between two marks also brings random error. It shows up as scatter: a slightly different number is obtained for the same quantity each time. Repeating the measurement makes the scatter visible, and in the mean the effect of random error is damped, although the scatter of the individual results does not get smaller: results that are too large and too small partly cancel each other.

    Systematic error

    A systematic error is almost the same in direction and size in every measurement. It comes, for example, from a wrong zero (a scale shows $1.2\,\text{g}$ when empty), from a badly adjusted instrument, or from the way of measuring, such as looking at a scale from the side. All results shift in the same direction, so they can be in a tight group but in the wrong place. Repeating and the mean do not remove it. It is noticed by comparing the result with a known reference value or with another method of measurement, and then it is corrected.

    Repeatability and accuracy

    The reliability of a measurement is described by two things. Repeatability tells how close to each other repeated measurements land, and it is weakened by random error. Accuracy tells how close the mean is to the true value, and it is weakened by systematic error. A measurement can be repeatable but not accurate, like the lower series in the figure. A reliable measurement has both.

    Mean and error estimate

    The best estimate of a repeated measurement is the mean of the results:

    mean
    $$\bar{x} = \frac{x_1 + x_2 + \dots + x_n}{n}$$

    where $\bar{x}$ is the mean, $x_1, x_2, \dots, x_n$ are the individual measurement results and $n$ is the number of measurements. The mean adds up the results and divides the sum by the number, so the more measurements there are, the less a single stray result affects it.

    In this course the scatter of repeated results, that is, the size of random error, is estimated with a simple approximate method, as half of the range:

    $$\Delta x = \frac{x_\text{max} - x_\text{min}}{2}$$

    where $\Delta x$ is the error estimate, $x_\text{max}$ is the largest and $x_\text{min}$ the smallest result. The error estimate, or measurement uncertainty, is not the measurement error itself, which is not known, but an estimate of how large the measurement error can be; it is always positive. The result is stated in the form $\bar{x} \pm \Delta x$. The error estimate is a rough estimate, not a strict limit: a single result can sometimes fall outside it. Half of the range describes the scatter of the individual results. The uncertainty of the mean is usually smaller, and the more measurements there are, the smaller it is, so for the mean $\Delta x$ is a cautious estimate. The method suits the measurements of this course with a few repeats; more exact methods are based on statistical scatter.

    Half of the range is a simple estimate of the scatter of the results, not a general method for finding the measurement uncertainty. It does not reveal a systematic error, which shifts all results in the same direction. If all the results are the same, no scatter shows, but the uncertainty is still not zero: then the reading uncertainty is estimated, as below.

    The error estimate is rounded to one significant figure, or to two if the first figure is 1. The result is rounded to the same decimal place: $3.18\,\text{s} \pm 0.12\,\text{s}$ and not $3.1817\,\text{s} \pm 0.12\,\text{s}$. This way the result has no figures that cannot be trusted because of the uncertainty.

    When the measurement is made only once and the value is read from a scale, in a simple situation the uncertainty of the reading can be estimated, for example, as half of the smallest scale division $d$:

    $$\Delta x = \frac{d}{2}$$

    With a ruler whose smallest scale division is $1.0\,\text{mm}$, the uncertainty of the reading can thus be estimated as $0.5\,\text{mm}$. However, the total uncertainty of a measurement can also be affected by the method of measurement, the instrument and other sources of error. The smallest scale division, or the step of the last figure of a display, is the resolution of the instrument, and it alone does not give the uncertainty: a stopwatch shows hundredths of a second, but the uncertainty of a time taken by hand is, because of reaction time, of the order of tenths of a second.

    The ratio of the error estimate, that is, the measurement uncertainty, to the result is called the relative uncertainty:

    $$\varepsilon = \frac{\Delta x}{\bar{x}} \cdot 100\,\%$$

    where $\varepsilon$ is the relative uncertainty as a percentage. It tells whether the uncertainty is small or large compared with the size of the result: an uncertainty of $0.5\,\text{mm}$ is small for measuring a metre but large for a wire one millimetre thick.

    A systematic error is estimated by measuring a quantity whose true value is known and comparing the mean of the measurements with this value. The reference can be, for example, an empty scale, ice water, whose temperature is $0\,{}^\circ\text{C}$, or a rod of precisely known length:

    $$\Delta x_\text{sys} = \bar{x}_\text{ref} - x_\text{true}$$

    where $\bar{x}_\text{ref}$ is the mean of the reference measurements and $x_\text{true}$ is the true value of the reference quantity. The corrected result is obtained by subtracting the error from the reading:

    $$x = x_\text{reading} - \Delta x_\text{sys}$$

    Common misconception

    Many people think that a precise instrument or many repeats guarantee a correct result. Even a precise instrument can be badly adjusted, and then its readings are in a tight group but in the wrong place. Repeats reduce random error but not systematic error, and good repeatability tells nothing about accuracy. Another misconception is to regard all error as carelessness. Carelessness causes a gross error, which is looked for and left out only for a justified and recorded reason, but random and systematic error belong to the result of a skilled measurer too, and that is why they are estimated and stated. A third is to calculate a mean of numbers that are in different units: the results are converted to the same unit first.

    Summary

    • A measurement error is the difference between the result and the true value, $x - x_\text{true}$. Every measurement result has some uncertainty. The error is usually not known, but its possible size is estimated as the measurement uncertainty and stated together with the result.
    • A gross error is a single mistake, such as a wrongly read or recorded reading. It often shows up as a result that clearly differs from the others, which is checked; the result is left out only if the cause of the error is found, and the cause is recorded.
    • A random error varies from one measurement to the next and shows up as scatter. In the mean $\bar{x}$ the effect of random error is damped, although the scatter of the individual results does not get smaller. In this course the scatter is estimated approximately by half of the range $\Delta x$, which is a cautious uncertainty estimate for the mean.
    • A systematic error shifts all results in the same direction, and repeating does not remove it. It is noticed with a reference value and corrected: $x = x_\text{reading} - \Delta x_\text{sys}$.
    • Repeatability tells about random error and accuracy about systematic error. A reliable measurement is both repeatable and accurate.
    • The result is stated in the form $\bar{x} \pm \Delta x$ with its unit. The error estimate is rounded to one significant figure (two if the first figure is 1), and the result to the same decimal place.

      Example 1: Rolling time and its uncertainty

      A student measures the rolling time of a ball on a ramp with a hand stopwatch six times and gets the results $3.12\,\text{s}$, $3.25\,\text{s}$, $3.07\,\text{s}$, $3.31\,\text{s}$, $3.19\,\text{s}$ and $3.15\,\text{s}$. What is the measurement result with its error estimate, and how large is the relative uncertainty?

      Step 1/7

      Given and find. The number of measurements is $n = 6$, and the smallest result is $t_\text{min} = 3.07\,\text{s}$ and the largest $t_\text{max} = 3.31\,\text{s}$. The mean $\bar{t}$, the error estimate $\Delta t$ and the relative uncertainty $\varepsilon$ are asked for.

      Step 2/7

      Principle. Hand timing has a random error, because reaction time varies. So the mean is taken as the result and half of the range as the error estimate. The relative uncertainty compares the error estimate with the result.

      Step 3/7

      Rearranged formula. $$\begin{aligned} \bar{t} &= \frac{t_1 + t_2 + \dots + t_n}{n} \\ \Delta t &= \frac{t_\text{max} - t_\text{min}}{2} \\ \varepsilon &= \frac{\Delta t}{\bar{t}} \cdot 100\,\% \end{aligned}$$

      Step 4/7

      Unit conversions. None needed: all times are in seconds, and the relative uncertainty is a number without a unit, which is multiplied by a hundred to get percent.

      Step 5/7

      Substitution. The sum of the results is

      $3.12\,\text{s} + 3.25\,\text{s} + 3.07\,\text{s} + 3.31\,\text{s} + 3.19\,\text{s} + 3.15\,\text{s}$
      $= 19.09\,\text{s}$

      Substitute it and the other numerical values with their units:

      $$\begin{aligned} \bar{t} &= \frac{t_1 + t_2 + \dots + t_n}{n} \\ &= \frac{19.09\,\text{s}}{6} \\ &= 3.1817\,\text{s} \\[4pt] \Delta t &= \frac{t_\text{max} - t_\text{min}}{2} \\ &= \frac{3.31\,\text{s} - 3.07\,\text{s}}{2} \\ &= 0.12\,\text{s} \\[4pt] \varepsilon &= \frac{\Delta t}{\bar{t}} \cdot 100\,\% \\ &= \frac{0.12\,\text{s}}{3.1817\,\text{s}} \cdot 100\,\% \\ &= 3.8\,\% \end{aligned}$$

      Step 6/7

      Result. The error estimate $0.12\,\text{s}$ is a number with two figures, because its first figure is 1. The mean is rounded to the same decimal place, so the measurement result is $t = 3.18\,\text{s} \pm 0.12\,\text{s}$. The relative uncertainty is $3.8\,\%$, two significant figures like the error estimate.

      Step 7/7

      Reasonableness. The interval $3.18\,\text{s} \pm 0.12\,\text{s}$, that is, $3.06\,\text{s}$–$3.30\,\text{s}$, covers five of the six results. The result $3.31\,\text{s}$ falls just outside it, which fits the fact that the error estimate is rough. The relative uncertainty is a few percent, which is usual for a hand-timed measurement. However, the repeats tell only about random error: a systematic error would be revealed only by comparison with another method of measurement.

      Example 2: Gross error

      A student measures the rolling time of a ball six times with a hand stopwatch and gets the results $3.12\,\text{s}$, $3.25\,\text{s}$, $3.07\,\text{s}$, $4.31\,\text{s}$, $3.19\,\text{s}$ and $3.15\,\text{s}$.What should she do before calculating the mean?

      • Correct. The result $4.31\,\text{s}$ differs from the others by more than a second, so it is probably a gross error, for example a stopwatch stopped late or a wrongly recorded reading. If the check reveals a gross error, the result is left out, the reason is recorded and a new measurement is made in its place. Merely differing from the others is not yet a reason to remove a result.

      • The error estimate describes random error, that is, ordinary scatter. A gross error is not scatter but a mistake, so including it would inflate the error estimate about sevenfold, from $0.09\,\text{s}$ to $0.62\,\text{s}$. A result that clearly differs is checked and the measurement is repeated if necessary; the result is left out only for a justified and recorded reason.

      • The extremes are not automatically wrong: $3.07\,\text{s}$ is only $0.05\,\text{s}$ smaller than the next result, and it belongs to the ordinary scatter. A result that clearly differs, here $4.31\,\text{s}$, is checked, and it is left out only if the cause of the error is found.

      • The mean damps random error, but the result $4.31\,\text{s}$ differs from the others by more than a second, while the others are within $0.2\,\text{s}$ of each other. It is probably a gross error, and if it were included, it would move the mean about $0.2\,\text{s}$ up.

      Optional Example 3: Find the error
      A student's ruler has a worn zero end, so all readings are about $0.4\,\text{cm}$ too large. She measures the length of a glass tube ten times and calculates the mean. She reasons: ten measurements cancel the errors, so the result is certainly correct.Where is the mistake?

      • Correct. A systematic error does not vary from one measurement to the next, so the mean does not damp it. It is noticed by comparing with a known length and corrected by subtracting.

      • Almost equal readings tell about repeatability, not accuracy. The zero end of the ruler is worn, so every reading is too large.

      • Picking results does not help if all readings are too large in the same way. Besides, discarding results to suit your wishes would distort the result.

      • Adding repeats does not help, because the error is in the same direction in every reading. In experiment 2 the 40 measurements of the model did not remove the systematic error $0.30\,\text{s}$.

      Example 4: Apply to a new situation

      A kitchen scale shows $0.8\,\text{g}$ when empty. A student weighs five similar coins together five times and gets the readings $27.9\,\text{g}$, $28.1\,\text{g}$, $28.0\,\text{g}$, $27.8\,\text{g}$ and $28.2\,\text{g}$.

      What is the mass of one coin? Answer in grams.

      g
      Hint 1: a guiding question

      Which kind of error is the zero reading of the scale and which kind is the variation of the readings? Each is handled differently.

      Hint 2: what is the connection

      First calculate the mean of the readings, then correct the zero by subtracting the zero reading, and finally divide by the number of coins.

      Hint 3: an intermediate step

      The sum of the readings is $27.9 + 28.1 + 28.0 + 27.8 + 28.2$ grams. The mean $\bar{m}$ is the sum divided by five, and the mass of one coin is $\dfrac{\bar{m} - 0.8\,\text{g}}{5}$.

      Show the solution

      Given

      zero reading of the scale $m_0 = 0.8\,\text{g}$; readings $27.9\,\text{g}$, $28.1\,\text{g}$, $28.0\,\text{g}$, $27.8\,\text{g}$ and $28.2\,\text{g}$; number of coins $N = 5$

      Find

      the mass of one coin $m_\text{coin}$ in the unit $\text{g}$

      Principle

      The variation of the readings is random error, which the mean damps. The zero reading $0.8\,\text{g}$ is a systematic error, which is in every reading and so in the mean, so it has to be subtracted. The total mass of five coins is finally divided by five.

      Formula

      $\bar{m}$$= \dfrac{m_1 + m_2 + m_3 + m_4 + m_5}{5}$
      $m_\text{coin}$$= \dfrac{\bar{m} - m_0}{N}$

      Conversions

      All masses are in grams, so no conversions are needed.

      Substitution

      The sum is

      $27.9\,\text{g} + 28.1\,\text{g} + 28.0\,\text{g} + 27.8\,\text{g} + 28.2\,\text{g}$
      $= 140.0\,\text{g}$

      so

      $\bar{m}$$= \dfrac{140.0\,\text{g}}{5}$
      $= 28.0\,\text{g}$
      $m_\text{coin}$$= \dfrac{28.0\,\text{g} - 0.8\,\text{g}}{5}$
      $= \dfrac{27.2\,\text{g}}{5}$
      $= 5.44\,\text{g}$

      Answer

      $5.44\,\text{g}$

      Three significant figures: the difference $27.2\,\text{g}$ is known to three figures, and division by $5$ is exact.

      Reasonableness

      Estimate: $28\,\text{g} : 5 \approx 5.6\,\text{g}$, and the correction reduces the mass by $0.8\,\text{g} : 5 = 0.16\,\text{g}$, so $5.6\,\text{g} - 0.16\,\text{g} \approx 5.44\,\text{g}$. The mass of a coin is of the order of a few grams, as with small coins, and the corrected mass is smaller than the reading, because the scale showed too much.

      Review the chapter's concepts

      Cards you mark Review later collect in your review deck.

      Quantity
      A measurable property, such as length, mass or time.
      Unit
      An agreed reference value in which a measured property is expressed.
      Measurement result
      The value of a quantity, made up of a number and a unit.
      Measurement error
      The difference between a measurement result and the true value of the quantity. It is usually not known, so its possible size is estimated as the measurement uncertainty.
      Random error
      A varying deviation whose effect can be reduced by repeating the measurement and taking the mean.
      Systematic error
      A deviation always in the same direction, caused for example by a faulty instrument or method.
      Gross error
      An obvious deviation caused for example by a misreading, a wrong entry or misuse of an instrument.
      Resolution of an instrument
      The smallest change in the reading that an instrument can show, for example the smallest scale division or the step of the display's last digit. On its own it does not give the uncertainty of the measurement.

      4. Calculation task

      The rolling time of a ball is measured five times and the results are $2.36\,\text{s}$, $2.41\,\text{s}$, $2.38\,\text{s}$, $2.46\,\text{s}$ and $2.39\,\text{s}$. The error estimate is half of the range.

      What percentage of the mean is it?

      %
      Hint 1: a guiding question

      First calculate the mean and half of the range.

      Hint 2: what is the connection

      The relative uncertainty is

      $\varepsilon$$= \dfrac{\Delta t}{\bar{t}} \cdot 100\,\%$
      Hint 3: an intermediate step

      The mean is $2.40\,\text{s}$ and half of the range is $\dfrac{2.46\,\text{s} - 2.36\,\text{s}}{2}$.

      Show the solution

      Given

      $t = 2.36\,\text{s}$, $2.41\,\text{s}$, $2.38\,\text{s}$, $2.46\,\text{s}$ and $2.39\,\text{s}$; $n = 5$, $t_\text{min} = 2.36\,\text{s}$, $t_\text{max} = 2.46\,\text{s}$

      Find

      the relative uncertainty $\varepsilon$ as a percentage

      Principle

      The estimate of random error is half of the range, and the relative uncertainty compares it with the result, which is the mean. The ratio has no unit, and you get percent by multiplying by a hundred.

      Formula

      $\bar{t}$$= \dfrac{t_1 + \dots + t_5}{n}$
      $\Delta t$$= \dfrac{t_\text{max} - t_\text{min}}{2}$
      $\varepsilon$$= \dfrac{\Delta t}{\bar{t}} \cdot 100\,\%$

      Conversions

      All times are in seconds, so no conversions are needed. The ratio is multiplied by a hundred to get percent.

      Substitution

      $\bar{t}$$= \dfrac{12.00\,\text{s}}{5}$
      $= 2.40\,\text{s}$
      $\Delta t$$= \dfrac{2.46\,\text{s} - 2.36\,\text{s}}{2}$
      $= 0.05\,\text{s}$
      $\varepsilon$$= \dfrac{0.05\,\text{s}}{2.40\,\text{s}} \cdot 100\,\%$
      $\approx 2.08\,\%$

      Answer

      $2\,\%$

      One significant figure like the error estimate $0.05\,\text{s}$ (calculator value $2.08\,\%$).

      Reasonableness

      Estimate: $0.05\,\text{s}$ is about $\tfrac{1}{50}$ of the time $2.4\,\text{s}$, that is, about $2\,\%$. For a hand-timed measurement a random error of a few percent is usual.

      5. Explanation task

      Explain in your own words how you tell random and systematic error apart, what repeating does to them, and what repeatability and accuracy mean.

      Model answer

      Random error varies each time and in either direction, so it shows as scatter in the results, for example the reaction time of a hand stopwatch. A systematic error is in the same direction in every measurement, for example a wrong zero. Repeating and the mean damp random error, because results that are too large and too small cancel each other, but a systematic error is just as large in the mean too. Repeatability tells how close to each other repeated results land, that is, how small the random error is. Accuracy tells how close to the true value the mean is, that is, how small the systematic error is. A systematic error can be noticed only by comparing the result with a known reference value or with another method of measurement.
