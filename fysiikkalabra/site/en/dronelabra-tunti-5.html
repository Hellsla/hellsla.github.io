Lesson 5 · Build and program the Air:bit

Your own radio controller

micro:bit, MakeCode and radio control

Two micro:bits communicate by radio: one is the controller, the other receives.

In this lesson you learn: You program a micro:bit to send control commands by radio.

Works with the present equipment

Start right away (5–10 min)

Load onto the micro:bit a program that sends a number by radio when you press button A. Try with your partner's micro:bit whether the number arrives.

The Air:bit 2 radio controller and control program →

Try · Modify · Challenge yourself

  1. Try for everyone

    Program the micro:bit to send its tilt and the state of the buttons by radio as named values. Show on the receiving micro:bit that the values change when you tilt the controller.

  2. Modify your own ideas

    Change the radio group to your group's own and add throttle control to the controller with buttons A and B so that the value stays between 0 and 100.

  3. Challenge yourself optional

    Add a safety feature: the controller sends permission to start only when A and B are pressed at the same time, and shows the state clearly.

What did you make?

Basic level: A controller program that sends tilt and throttle by radio on the group's own channel.

Challenge yourself: A controller with a two-button start safeguard.

Write in your project diary

  • a screenshot of the program
  • the number of the group's radio group
  • how you tested that the message gets through

Together

Try your partner's controller and tell them one thing that would make it easier to use.

You need

  • two micro:bits per group
  • a computer and MakeCode
  • USB cable
  • a battery holder for the controller

Step-by-step guide

  • The Air:bit 2 radio controller and control program

Starter files

  • Air:bit controller starter program (MakeCode, JavaScript) untested draft: the teacher tries it without propellers before use

Safety

In this lesson you program and test on the desk. The drone's battery is not connected.

For the teacher: preparation and timing

Timing: First radio message 10 min, controller program 40 min, radio groups and throttle 15 min, summary 10 min. The manufacturer estimates 3–4 hours for programming the controller, so the work continues next time.

Preparation: Give each group its own radio group number. Keep the manufacturer's ready-made controller program in reserve for groups whose own program is not finished.
