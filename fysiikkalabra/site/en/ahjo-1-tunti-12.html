Lesson 12 · Robotics

A robot that carries a load

Getting the robot moving

A ready robot base, motors, a test program, measuring speed and a load test.

In this lesson you learn: You program a ready robot base and measure its speed and how much it carries.

Start right away (5–10 min)

Take a ready-assembled robot base and upload the starter test sketch to it. Try the program first with the wheels in the air, then drive the robot forwards and backwards on the floor.

Try · Modify · Challenge yourself

  1. Try for everyone

    Measure the robot's speed: drive straight for a set time, measure the distance with a tape measure and work out the speed. Repeat three times and change the program's SPEED number.

  2. Modify your own ideas

    Make a cardboard load bay for the robot. Test how many grams the robot carries one metre without the load falling or the robot stopping. Improve one thing and test again.

  3. Challenge yourself optional

    Assemble a robot base yourself from parts as the teacher instructs, or compare three SPEED values: how do the speed and the load it carries change?

If you have to wait

If there are fewer robots than groups, design a cardboard load bay meanwhile. From the speed another group measured, work out how long a drive one metre takes, and test the calculation when the robot is free.

What did you make?

Basic level: The speed measured three times, your own load bay and the load the robot carries one metre, before and after one improvement.

Challenge yourself: A robot base you assembled yourself, or a table comparing three speed settings.

Together

Compare load bays with another group: whose solution carries more, and why?

You need

  • ready-assembled Arduino robot base: Arduino Uno, two DC motors, a motor driver and a battery for the motors (in the challenge you can assemble it yourself)
  • the starter test sketch (check the pins for your motor driver)
  • cardboard and tape for the load bay
  • load: coins or weights
  • kitchen scale, tape measure and stopwatch

Step-by-step guide

  • Small extra challenge: A cardboard automaton

Starter files

  • Load test table (CSV) spreadsheet template
  • Robot test sketch (Arduino) untested draft: the robot base is not chosen yet, check the pins

Safety

Test a new program first with the robot's wheels in the air on a stand. Drive the robot on the floor in a clear area. Disconnect the motor battery when you change the wiring.
