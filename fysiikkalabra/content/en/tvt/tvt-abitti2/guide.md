The exam system of the matriculation examination is Abitti 2, and it has its own programs for making a graph, a table or a calculation. In this guide you see which programs there are, how answers are saved and how to practise the tools before the exam.

## Why you need this

In a physics exam, a graph, a table or a long calculation is made on the computer, and the answer is written in the answer field of the exam system. There is no time to learn the tools during the exam, so get to know them beforehand. The guide is based on the pages of YTL and Abitti themselves; the sources and the reading date are at the end of the guide. The guide does not replace the pages of YTL and Abitti, because the exam system is updated.

## Steps

1. **Check which exam system is in use.** YTL says that Abitti 2 has been taken into use in the matriculation examination from the autumn 2026 examination onwards, and that since 16.4.2026 it has been the only exam system used for practice (YTL, updated 14.8.2026). You get the instructions for practice exams from your own upper secondary school.

2. **See which programs the exam system has.** The programs are in the application menu of the exam environment. The physics-related ones in YTL's list (updated 27.11.2026) are the following. Using the exam system does not require buying the programs or accepting a licence.

    | Program | Use |
    |---|---|
    | Collabora Calc | spreadsheet |
    | Collabora Writer, Draw and Impress | word processing, vector graphics and presentations |
    | GeoGebra Math Apps Bundle | symbolic computation |
    | Vernier Graphical Analysis Pro | analysing measurement data (the school can install it with its own code) |
    | Abicus | function calculator |
    | Draw.io, Klecks | image editing |
    | Mafy tables, MAOL digital tables | tables (the school can install them with its own code) |
    | PDF.js | PDF reader |

    The list also includes, among others, Abicode, Ketcher and TI ExamCalc. YTL says that in the exam it is enough to master one program for each purpose. So choose a program and learn it well, not all of them.

3. **Ask your school which programs are included in practice.** The school can install some programs with its own installation code. Ask whether Graphical Analysis Pro and the tables (Mafy or MAOL) are installed, and try them in a practice exam.

4. **Write the answer in the answer field of the question.** YTL instructs students to answer directly in the answer fields next to the questions. The exam system saves the answers in the answer fields automatically.

5. **Save the files you make with the programs, such as a graph or a table, yourself.** Save the files you make with the programs regularly so that they are backed up to the server.

6. **Attach a screenshot to the answer in an open task.** Abitti says that a screenshot from an auxiliary program can be attached to the exam answer in open tasks. The steps for attaching belong to the exam system's own instructions, which you reach from the link *Koejärjestelmän ohjeet* on YTL's page of auxiliary programs. This guide does not describe them (see *What this guide does not yet tell*).

7. **Check your answers before you end the exam.** You can scroll to the end of the exam and choose **Siirry tarkastelemaan vastauksiasi**; from there you can go back to editing. When you press **Päätä koe**, you can no longer go back to editing the exam.

## How to practise the source-material mini exam with the tools

It is worth doing the source-material mini exam of the FY9 course ($60\,\text{min}$) with the tools that are in the exam too. Use a spreadsheet and GeoGebra on your own computer, or the school's practice exam environment if the school offers one. Make the graph with a program and check that the axes have the quantities and the units. Instructions for making a graph are in the guides [[ohje:tvt-kuvaaja|Mittauspisteiden kuvaaja]], [[ohje:tvt-suoran-sovitus|Suoran sovittaminen mittauspisteisiin]] and [[ohje:tvt-taulukkolaskenta|Taulukko ja lasketut sarakkeet]]. They describe the school's Graphical Analysis Pro, whose Abitti 2 version is listed but has not been compared here.

## Common mistakes

- **Learning the tools only in the exam.** Try the programs in a practice exam before you need them.
- **A file is left unsaved.** The content of an answer field is saved by itself, but a file you make in a program has to be saved.
- **Ending the exam by accident.** Review your answers before you press **Päätä koe**.
- **Assuming the guide is up to date.** The information in this guide is from the reading date 28.11.2026. Check current information on the pages of YTL and Abitti.

## What this guide does not yet tell

This guide does not describe how formulas are written in an answer, how a graph is made step by step with the programs of the exam system, or how a file is attached to an answer, because these have not been confirmed from the sources. Look them up in the exam system's own instructions.
