## fy1-2-L1-01
**Given:** thickness of a hair $l = 82\,\mu\text{m}$
**Find:** the thickness $l$ in millimetres
**Principle:** A quantity does not change when its unit is changed; only the numerical value changes. The prefix micro means a factor of $10^{-6}$ and the prefix milli a factor of $10^{-3}$, so $1\,\mu\text{m} = 10^{-3}\,\text{mm}$.
**Formula:** $1\,\mu\text{m} = 10^{-3}\,\text{mm}$
**Conversions:** In place of the micrometre we write its value in millimetres, $10^{-3}\,\text{mm}$.
**Substitution:** $l = 82\,\mu\text{m} = 82\cdot 10^{-3}\,\text{mm} = 0.082\,\text{mm}$
**Answer:** $0.082\,\text{mm}$, two significant figures like the initial value $82\,\mu\text{m}$ (the leading zero is not significant).
**Reasonableness:** A millimetre is a thousand times larger unit than a micrometre, so the numerical value must become a thousand times smaller: from 82 to 0.082. A hair is slightly less than a tenth of a millimetre thick, which fits experience.

## fy1-2-L1-02
**Given:** distance between the Earth and the Moon $s = 384\,400\,\text{km}$; $1\,\text{Mm} = 10^{6}\,\text{m}$
**Find:** the distance $s$ in megametres
**Principle:** The distance is the same regardless of the unit. The prefix mega is $10^{6}$ and the prefix kilo $10^{3}$, so $1\,\text{Mm} = 10^{3}\,\text{km}$.
**Formula:** $1\,\text{km} = 10^{-3}\,\text{Mm}$
**Conversions:** A megametre is a thousand kilometres, so a kilometre is a thousandth of a megametre. In place of the kilometre we write $10^{-3}\,\text{Mm}$.
**Substitution:** $s = 384\,400\,\text{km} = 384\,400\cdot 10^{-3}\,\text{Mm} = 384.4\,\text{Mm}$
**Answer:** $384.4\,\text{Mm}$, four significant figures. The trailing zeros of the whole number $384\,400$ are unclear, so the number is interpreted as precise to a hundred kilometres, $3.844\cdot10^{5}\,\text{km}$, and $1\,\text{km} = 10^{-3}\,\text{Mm}$ is exact.
**Reasonableness:** A megametre is a thousand kilometres, and 384 400 is about 400 thousand, so the result is about 400 Mm. The power of ten of the distance lies between $10^{8}\,\text{m} = 100\,\text{Mm}$ and $10^{9}\,\text{m} = 1000\,\text{Mm}$, as it should.

## fy1-2-L1-03
**Given:** length $l = 1.85\,\text{m}$ (three significant figures), width $w = 0.92\,\text{m}$ (two significant figures)
**Find:** the area $A$ in square metres
**Principle:** The area of a rectangle is the product of its sides. The number of significant figures in a product is the same as in the least precise factor: the result cannot be given more precisely than the measurement result with the lowest precision.
**Formula:** $A = l\,w$
**Conversions:** Not needed: both sides are already in metres, so the area comes out in the unit $\text{m}\cdot\text{m} = \text{m}^2$.
**Substitution:** $A = 1.85\,\text{m}\cdot 0.92\,\text{m} = 1.702\,\text{m}^2$
**Answer:** $1.7\,\text{m}^2$, two significant figures, because the width $0.92\,\text{m}$ is the least precise piece of data.
**Reasonableness:** With rounded numbers $2\,\text{m}\cdot 1\,\text{m} = 2\,\text{m}^2$, and the result 1.7 is slightly smaller, because both sides were rounded upwards. The square metre is a unit of area, as it should be.

## fy1-2-L1-04
**Given:** speed $v = 15.341\,\text{km/s}$
**Find:** the speed $v$ in the unit $\text{m/s}$
**Principle:** The speed unit $\text{km/s}$ is a unit of length divided by a unit of time; only the unit of length changes, the second stays. The prefix kilo is $10^{3}$, so $1\,\text{km} = 1000\,\text{m}$.
**Formula:** $1\,\text{km} = 1000\,\text{m}$, so $1\,\dfrac{\text{km}}{\text{s}} = 1000\,\dfrac{\text{m}}{\text{s}}$
**Conversions:** In place of the kilometre we write $1000\,\text{m}$; the second stays.
**Substitution:** $v = 15.341\,\dfrac{\text{km}}{\text{s}} = 15.341\cdot\dfrac{1000\,\text{m}}{\text{s}} = 15\,341\,\dfrac{\text{m}}{\text{s}}$
**Answer:** $15\,341\,\text{m/s}$, five significant figures like the initial value $15.341\,\text{km/s}$.
**Reasonableness:** A metre is a smaller unit than a kilometre, so the numerical value must become a thousand times larger. About 15 km/s is more than 40 times the speed of sound, 340 m/s, which fits a space probe.

## fy1-2-L1-05
**Given:** the diameter of the Moon $D_\text{Moon} = 3474\,\text{km}$ corresponds to one pixel; the diameter of the Sun $D_\text{Sun} = 1.392\cdot10^{6}\,\text{km}$
**Find:** the width of the Sun in pixels $N$
**Principle:** The picture is drawn to scale, so all lengths shrink in the same ratio. The number of pixels is the ratio of the length to the diameter of the Moon.
**Formula:** $N = \dfrac{D_\text{Sun}}{D_\text{Moon}}\cdot 1\,\text{px}$
**Conversions:** Not needed: both diameters are in kilometres and the units cancel.
**Substitution:** $N = \dfrac{1.392\cdot10^{6}\,\text{km}}{3474\,\text{km}}\cdot 1\,\text{px} = 400.69\,\text{px}$
**Answer:** $400.7\,\text{px}$, four significant figures like the initial values $1.392\cdot10^{6}\,\text{km}$ and $3474\,\text{km}$.
**Reasonableness:** Roughly $\dfrac{1.4\cdot10^{6}}{3.5\cdot10^{3}} = 0.4\cdot10^{3} = 400$. The diameter of the Sun is about 400 Moons, which fits the fact that it is much larger than the Moon.

## fy1-2-L2-01
**Given:** clock frequency $f = 3.2\,\text{GHz}$, time $t = 5.0\,\text{ms}$; $1\,\text{GHz} = 10^{9}\,\text{Hz}$ and $1\,\text{Hz} = 1/\text{s}$
**Find:** the number of clock cycles $N$
**Principle:** The frequency tells how many cycles occur in a second. When the frequency is constant, the number of cycles is the product of the frequency and the time. The frequency and the time must be given in the same unit of time, so both are converted to SI units.
**Formula:** $N = f\,t$
**Conversions:** $f = 3.2\,\text{GHz} = 3.2\cdot10^{9}\,\text{Hz} = 3.2\cdot10^{9}\,\text{1/s}$ and $t = 5.0\,\text{ms} = 5.0\cdot10^{-3}\,\text{s}$.
**Substitution:** $N = 3.2\cdot10^{9}\,\dfrac{1}{\text{s}}\cdot 5.0\cdot10^{-3}\,\text{s} = 16\cdot10^{6} = 1.6\cdot10^{7}$
**Answer:** $16\,000\,000$, that is $1.6\cdot10^{7}$ cycles, two significant figures like the initial values $3.2\,\text{GHz}$ and $5.0\,\text{ms}$.
**Reasonableness:** Three gigahertz is about three billion cycles per second. A millisecond is a thousandth of a second, so in one millisecond there are about three million cycles, and in five about $5\cdot 3 = 15$ million. The result $16$ million agrees with the estimate.

## fy1-2-L2-02
**Given:** length of a bacterium $l = 2.0\,\mu\text{m}$, distance $L = 1.0\,\text{mm}$
**Find:** the number of bacteria $N$
**Principle:** The number is the ratio of the distance to the length of one bacterium. The ratio is meaningful only when both lengths are in the same unit, so one of them is converted.
**Formula:** $N = \dfrac{L}{l}$
**Conversions:** $L = 1.0\,\text{mm} = 1.0\cdot10^{-3}\,\text{m}$ and $l = 2.0\,\mu\text{m} = 2.0\cdot10^{-6}\,\text{m}$.
**Substitution:** $N = \dfrac{1.0\cdot10^{-3}\,\text{m}}{2.0\cdot10^{-6}\,\text{m}} = 0.50\cdot10^{3} = 5.0\cdot10^{2} = 500$
**Answer:** $500$ bacteria, two significant figures like the initial values $1.0\,\text{mm}$ and $2.0\,\mu\text{m}$.
**Reasonableness:** A millimetre is a thousand micrometres, so 1000 objects one micrometre long would fit in 1 mm. A bacterium is two micrometres long, so half as many fit, 500.

## fy1-2-L2-03
**Given:** area $A = 2.4\,\text{km}^2$; $1\,\text{ha} = 10\,000\,\text{m}^2$
**Find:** the area $A$ in hectares
**Principle:** In place of a unit we write its value in another unit. The unit of area is a product of two lengths, so $1\,\text{km}^2 = 1000\,\text{m}\cdot1000\,\text{m} = 10^{6}\,\text{m}^2$, not $1000\,\text{m}^2$. After that we calculate how many hectares fit in that number of square metres.
**Formula:** $1\,\text{km}^2 = 10^{6}\,\text{m}^2$ and $1\,\text{ha} = 10^{4}\,\text{m}^2$, so $1\,\text{km}^2 = 10^{6} : 10^{4}\,\text{ha} = 100\,\text{ha}$
**Conversions:** In place of the square kilometre we write $100\,\text{ha}$.
**Substitution:** $A = 2.4\,\text{km}^2 = 2.4\cdot100\,\text{ha} = 240\,\text{ha}$
**Answer:** $240\,\text{ha}$, written as $2.4\cdot10^{2}\,\text{ha}$, two significant figures like the initial value $2.4\,\text{km}^2$.
**Reasonableness:** A square kilometre is 100 hectares, because $10^{6} : 10^{4} = 10^{2}$. So 2.4 square kilometres is 2.4 hundreds, that is 240 hectares.

## fy1-2-L2-04
**Given:** speed $v = 15.341\,\text{km/s}$ (constant), time $t = 1\,\text{day}$
**Find:** the distance $s$ in millions of kilometres ($10^{6}\,\text{km}$)
**Principle:** By assumption the probe moves at a constant speed, so the distance is the product of speed and time. The time must be given in seconds so that it fits the unit of speed.
**Formula:** $s = vt$
**Conversions:** $1\,\text{day} = 24\cdot 3600\,\text{s} = 86\,400\,\text{s}$. Finally $1\,\text{million km} = 10^{6}\,\text{km}$.
**Substitution:** $s = 15.341\,\dfrac{\text{km}}{\text{s}}\cdot 86\,400\,\text{s} = 1\,325\,462\,\text{km} = 1.3255\cdot10^{6}\,\text{km}$
**Answer:** $1.3255$ million km, five significant figures like the speed $15.341\,\text{km/s}$; the length of a day is exact.
**Reasonableness:** With rounded numbers $15\,\text{km/s}\cdot 9\cdot10^{4}\,\text{s} = 1.35\cdot10^{6}\,\text{km}$. In a day the probe travels a little over a million kilometres, about three times the distance from the Earth to the Moon.

## fy1-2-L3-01
**Given:** $c = 2.998\cdot10^{5}\,\text{km/s}$, $1\,\text{a} = 3.156\cdot10^{7}\,\text{s}$, $1\,\text{AU} = 1.496\cdot10^{8}\,\text{km}$
**Find:** the length of one light-year $L$ in astronomical units
**Principle:** The light-year is a unit of length, not of time: it is the distance light travels in a year. Light travels at a constant speed, so the given formula $s = ct$ gives the distance in kilometres, and then the distance is divided by the length of an AU.
**Formula:** $L = c\,t$
**Conversions:** $t = 1\,\text{a} = 3.156\cdot10^{7}\,\text{s}$ is already in seconds. In astronomical units the distance is obtained by calculating how many AU ($1.496\cdot10^{8}\,\text{km}$) fit in it.
**Substitution:** $L = 2.998\cdot10^{5}\,\dfrac{\text{km}}{\text{s}}\cdot 3.156\cdot10^{7}\,\text{s} = 9.462\cdot10^{12}\,\text{km}$ and $9.462\cdot10^{12}\,\text{km} : 1.496\cdot10^{8}\,\text{km} = 6.325\cdot10^{4}$, so $L = 6.325\cdot10^{4}\,\text{AU}$
**Answer:** $63\,250\,\text{AU}$, written as $6.325\cdot10^{4}\,\text{AU}$, four significant figures like the initial values.
**Reasonableness:** Light travels one AU in 8.3 minutes, and a year has about $525\,600$ minutes. The ratio $525\,600 : 8.3 \approx 63\,000$ confirms the result.

## fy1-2-L3-02
**Given:** screen width $W = 1920\,\text{px}$ (exact number); diameter of the Moon $D = 3474\,\text{km} = 1\,\text{px}$; distance $a = 30.07\,\text{AU}$; $1\,\text{AU} = 1.496\cdot10^{8}\,\text{km}$
**Find:** the number of screens $N$
**Principle:** The picture is drawn to scale, so kilometres become pixels when divided by the diameter of the Moon. The number of screens is the number of pixels divided by the width of one screen.
**Formula:** $N = \dfrac{a\cdot 1\,\text{AU}}{D}\cdot\dfrac{1\,\text{px}}{W}$
**Conversions:** The distance in kilometres: $30.07\cdot 1.496\cdot10^{8}\,\text{km} = 4.498\cdot10^{9}\,\text{km}$. Every $3474\,\text{km}$ is one pixel, so the number of pixels is $4.498\cdot10^{9}\,\text{km} : 3474\,\text{km} = 1.295\cdot10^{6}$.
**Substitution:** $N = \dfrac{1.295\cdot10^{6}\,\text{px}}{1920\,\text{px}} = 674.4$
**Answer:** $674.4$ screen widths, four significant figures like the data $30.07\,\text{AU}$, $1.496\cdot10^{8}\,\text{km}$ and $3474\,\text{km}$; the screen width $1920\,\text{px}$ is an exact number and does not limit the precision.
**Reasonableness:** Neptune is about 1.3 million pixels away, and 1.3 million divided by two thousand is about 650. The result is of the same order of magnitude, so the distance cannot be scrolled through in the picture at a glance.

## fy1-2-L3-03
**Given:** distance $d = 145\,\text{AU}$, $1\,\text{AU} = 1.496\cdot10^{8}\,\text{km}$, $c = 2.998\cdot10^{5}\,\text{km/s}$; the command arrives and the confirmation returns immediately
**Find:** the time $t$ for the whole round trip in hours
**Principle:** Light travels at a constant speed $c$, so the given formula $s = ct$ gives the time. The command and the confirmation each travel the distance $d$, so the whole distance is $2d$, not just $d$.
**Formula:** $t = \dfrac{2d}{c}$
**Conversions:** $d = 145\cdot 1.496\cdot10^{8}\,\text{km} = 2.169\cdot10^{10}\,\text{km}$. Finally $1\,\text{h} = 3600\,\text{s}$.
**Substitution:** $t = \dfrac{2\cdot 2.169\cdot10^{10}\,\text{km}}{2.998\cdot10^{5}\,\text{km/s}} = 1.447\cdot10^{5}\,\text{s}$. The number of hours is $1.447\cdot10^{5}\,\text{s} : 3600\,\text{s} = 40.2$, so $t = 40.2\,\text{h}$
**Answer:** $40.2\,\text{h}$, three significant figures like the distance $145\,\text{AU}$.
**Reasonableness:** In one direction light takes about $145\cdot 8.3\,\text{min} = 1200\,\text{min} = 20\,\text{h}$, so there and back is about 40 hours. The reply therefore arrives after more than a day.
